This repository contains the source code for my personal portfolio and digital garden, designed to showcase my work in computational science, data science, and systems engineering. Built entirely from scratch with zero-dependency vanilla HTML, CSS, and JavaScript, the site features a "Scientific Modernism" aesthetic alongside a custom, physics-based interactive knowledge graph that visualizes the connections between my skills and projects. It serves as a curated, living archive of my technical essays, research deep dives, and independent software products, demonstrating that elegant, high-performance web experiences can be achieved without relying on heavy frameworks.
