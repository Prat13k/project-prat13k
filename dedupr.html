$ cat abstract.md

Dedupr is a production-grade systems tool designed to solve storage bloat. Built entirely in Rust, it leverages BLAKE3 hashing for mathematically zero-collision identification.

By grouping files by size first and then hashing them concurrently across threads, Dedupr eliminates the O(N²) performance bottleneck of traditional duplicate finders. It features multiple output serialization formats (JSON/JSONL) for pipeline integration, localized translations, and safe, non-destructive dry-runs by default.

$ cat architecture.txt
1. Workspace Architecture

The project is split into modular crates: dedupr-core (logic), dedupr-i18n (translations), and dedupr-cli (interface). This ensures separation of concerns and testability.

2. Concurrent Hashing Pipeline

Files with matching sizes are passed to a thread pool via rayon. BLAKE3 splits the file into chunks and hashes them in parallel, saturating the CPU and disk I/O for maximum throughput.

3. Multi-Format Serialization

Using serde, the hash map results are cleanly serialized into JSON, JSONL (for database ingestion), or formatted CLI text with localized strings injected dynamically.
