Dedupr

Find and Destroy Duplicates. Instantly.

A zero-dependency Rust CLI that scans your drives, identifies exact duplicate files using BLAKE3 cryptographic hashing, and reclaims your disk space in milliseconds.

Under the Hood

1. BLAKE3 Hashing Engine

Dedupr doesn't just check file names or sizes; it checks the exact bytes. By utilizing the BLAKE3 cryptographic hash function, Dedupr is able to hash files at speeds exceeding 1 GB/s per core, making it exponentially faster than older tools using MD5 or SHA-256.

2. Zero Dependencies (Pure Rust)

Compiled natively with Rust, Dedupr drops a single, portable ~500KB executable. No Python runtimes, no Node modules, no Docker. It utilizes Rust's memory safety and multi-threading via `rayon` to scan multiple directories simultaneously without memory leaks.

3. Safe & Deterministic Removal

Safety is paramount. Dedupr operates in a dry-run state by default. It mathematically guarantees that files sharing a hash are exact duplicates before any deletion occurs. You can preview deletions before committing them to disk.
