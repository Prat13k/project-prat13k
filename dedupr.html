$ cat abstract.md

Dedupr is a systems-level tool designed to solve the problem of storage bloat. Traditional duplicate finders rely on slow file I/O or insecure MD5 hashing. Dedupr leverages Rust for memory-safe concurrency and BLAKE3 for lightning-fast cryptographic hashing.

By grouping files by size first, and then hashing them concurrently, Dedupr eliminates the O(N²) performance bottleneck of naive comparison algorithms. It is a demonstration of low-level systems programming applied to real-world data management.

$ cat architecture.txt
1. Directory Traversal

Uses `walkdir` to build an in-memory representation of the file system, grouping files by exact byte size to immediately discard non-matches.

2. Concurrent Hashing

Files with matching sizes are passed to a thread pool via `rayon`. BLAKE3 splits the file into chunks and hashes them in parallel, saturating the CPU and disk I/O.

3. Safe Removal

Hashes are compared in a HashMap. Only files with a 100% cryptographic match are flagged. The CLI prompts the user before executing the `std::fs::remove_file` command.
